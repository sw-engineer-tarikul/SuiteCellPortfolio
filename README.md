## 🚀 Getting Started & Local Preview

This project is built with zero runtime dependencies. You can preview it immediately in any modern browser.

### Option 1: Direct File Opening
Double-click `index.html` or open it in your browser of choice (Chrome, Edge, Safari, Firefox).

### Option 2: Local HTTP Server
Using Python:
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000`.

Using Node `npx serve`:
```bash
npx serve .
```

## 🚢 Deployment

You can deploy this static landing page instantly to:
- **Vercel**: Run `vercel` in this folder.
- **Netlify**: Drag and drop the folder into Netlify Drop or run `netlify deploy`.
- **GitHub Pages**: Push this directory to a GitHub repository and enable Pages in Settings.
- **Cloudflare Pages**: Connect your Git repo or upload the folder directly.
